title: Guides
description: Step-by-step instructions you can follow at your own desk, one task per guide.
---

Guides are hands-on. Each one walks through a single task, shows every step in at least two ways when the steps differ (for example in the terminal and in VS Code), and ends with a way to check that it worked.

## Planned

The first guides arrive with the sessions that need them:

- Install Claude Code (terminal, desktop app, VS Code)
- Open a folder as a project
- Markdown in ten minutes
- Git for humans: save points for your files
- Connect a tool: calendar, mail, documents

Until then, the [[Roadmap]] shows when each topic comes up.
